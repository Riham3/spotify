# Riham Blogs' Spotify Lyric Card Creator
**Try it out at:** [https://cigarettesprettysmokes.pages.dev/spotify/](https://cigarettesprettysmokes.pages.dev/spotify/)
 
It's an opinionated web page for generating Spotify-style lyric images with rich customization options, which can be exported in high resolution for social media sharing. You can choose the background and text colors, use a custom artwork image, and provide artist, track, and lyrics information.
 
Go to the 'Export' tab to upload custom artwork by providing a link ("https://" is not required) or selecting an image file directly. Find high-res artwork images using Riham Blogs' [Deezer Artwork Finder](https://cigarettesprettysmokes.pages.dev/deezer/). The image you upload directly stays in your browser as everything runs locally (see Riham Blogs' [Privacy Policy](https://cigarettesprettysmokes.pages.dev/privacy/)). 
 
This page is a parody and not associated with Spotify in any way. My watermark can be removed before export. It's possible to edit the preview directly instead of using the inputs. Click the text you want to edit, and the related input values update automatically as you type.
 
**NOTE:** A third-party CORS proxy is used to render the artwork for the exported image if you provide a link (not the case if you upload it directly). Your IP address and image link are sent to enable canvas export (which is retained by the service for 7 days). Please read weserv.nl's [Privacy Policy](https://github.com/weserv/images/blob/5.x/Privacy-Policy.md).
